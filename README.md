## Sobre o projeto

O projeto consiste no desenvolvimento de um aplicativo para organizar e facilitar o acesso aos livros disponíveis na biblioteca da escola. A plataforma permite que os alunos pesquisem livros de forma rápida e encontrem informações importantes sobre cada obra.

O aplicativo contará com uma **barra de pesquisa** e diferentes **filtros**, permitindo procurar livros por autor, gênero, número de páginas, entre outras informações. Cada livro terá uma página com dados como **título, autor, gênero, número de páginas e capa**.

Além disso, o aplicativo terá uma área de **recomendações personalizadas**. Essas recomendações serão baseadas nos livros que o aluno já pegou emprestado, sugerindo outras obras com características e temas semelhantes aos livros que ele demonstrou interesse.

### Objetivo do Projeto

O principal objetivo é tornar a utilização da biblioteca escolar mais prática, organizada e acessível aos alunos. O aplicativo busca facilitar a busca por livros e incentivar a leitura através de recomendações baseadas no histórico de empréstimos de cada aluno.

## Tecnologias

O projeto poderá utilizar tecnologias de desenvolvimento **Web**, como:

* **HTML** — estrutura das páginas;
* **CSS** — estilização e organização visual;
* **JavaScript** — funcionalidades e interações do aplicativo;
* **Banco de dados** — armazenamento das informações dos livros e dos empréstimos.

## Instalação e Uso

Para utilizar o projeto, é necessário ter acesso aos arquivos do sistema e abrir a aplicação em um navegador compatível.

Após iniciar o aplicativo, o usuário poderá:

1. Acessar a biblioteca de livros;
2. Pesquisar um livro pela barra de pesquisa;
3. Utilizar filtros por **autor, gênero e número de páginas**;
4. Visualizar a **capa e as informações** de cada livro;
5. Consultar a área de **recomendações**;
6. Receber sugestões de livros semelhantes aos que já foram emprestados anteriormente.

O sistema tem como finalidade facilitar a navegação pela biblioteca e ajudar os alunos a encontrar novas obras de acordo com seus interesses de leitura.
